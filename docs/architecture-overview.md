# 架构概览

该展示版仅说明产品分层，不提供可运行服务或内部实现。

1. **数据输入层**：接收 Excel 或 CSV 的订单、商品、库存和广告报表。
2. **数据处理层**：完成字段标准化、数据校验和基础关联。
3. **分析层**：按商品、站点、时间和活动维度计算指标，识别经营风险。
4. **展示层**：通过 Dashboard、表格和图表呈现经营结果与待办问题。
5. **部署层**：可部署为 Cloud Web Service，供演示或内部使用。

自然语言问答仅将业务问题映射到已计算的指标和可追溯证据，输出用于辅助判断的初步建议。

本仓库不包含内部接口地址、数据连接信息、实现代码、规则细节或模型配置。
